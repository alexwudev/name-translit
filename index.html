原文譯名
  • 譯音表是中國大陸標準（地名依各語言的 GB/T 17693 系列與 MZ/T 127-2019；人名依新華社《世界人名翻译大辞典》等）。台灣已有通行譯名（倫敦、莫斯科、雅加達、蒙哥馬利）或中文維基已有條目名時，以通行譯名為準，不要用本工具改。
  • 人名常有新華社逐條收錄的慣譯（加西亞、穆罕默德、馬丁），與照表譯出的結果不同；寫條目時先查中文維基或辭典，查不到才用本工具。
  • 黃字是另列的版本：通名意譯（湖、河、山、港）、印尼語「e 若讀 é」、西班牙語拉丁美洲讀音、阿拉伯語人名的地名表版本等，依情況選用。
  • 同一格有兩個字（萊／雷、奧／歐）或女性用字時，取第一個；勾選「顯示音節與來源」可看到另一個。

給 AI 與程式呼叫

完整說明（純文字，適合直接交給 AI 讀）：llms.txt

命令列（需要 Python 3.9 以上與網路；本頁與命令列跑的是同一份程式，結果相同）

pip install "git+https://github.com/alexwudev/name-translit"
name-translit <語言> <place|person> <原文…> [--json] [-v]

name-translit fi place Kuuterselkä Leitimojärvi
name-translit de person "Erich von Manstein" --json
uvx --from git+https://github.com/alexwudev/name-translit name-translit es place Valladolid   # 有 uv 時免安裝
  • 語言：fi 芬蘭語、ru 俄語（西里爾字母）、id 印尼語、en 英語、fr 法語、de 德語、es 西班牙語、fa 波斯語（拉丁轉寫）、ar 阿拉伯語（拉丁轉寫）、he 希伯來語（拉丁轉寫）。
  • --json 輸出 [{"src","zh","extra":{說明:版本},"detail":[…]}]；-v 附音節與逐字來源。原文可給多個，不給時從標準輸入每行讀一個。
